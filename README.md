# حریر رویا · Zarincode_Harir

قالب فروشگاهی کاملاً المنتوری، راست‌چین و فارسی برای کالای خواب — به‌همراه افزونهٔ
هستهٔ اختصاصی (قیمت‌گذاری عمده نقش‌محور، پنل کاربری دومنظوره، احراز هویت پیامکی).

**طراح و توسعه‌دهنده:** احسان نادری پناه · [zarincode.com](https://zarincode.com) · ۰۹۰۲۴۵۶۱۰۰۱

## اجزا

```
theme/zarincode-harir/          قالب — لایهٔ ارائه
plugin/zarincode-harir-core/    هسته — لایهٔ منطق (افزونهٔ همراه)
html-reference/                 منبع HTML طراحی (فقط مرجع)
tools/php-lint.py               ابزار بررسی نحو PHP
```

## حداقل نیازمندی‌ها

| مورد | نسخه |
|---|---|
| PHP | ۷٫۴ یا بالاتر (سازگار تا ۸٫۴) |
| WordPress | ۶٫۰ یا بالاتر |
| WooCommerce | ۷٫۰ یا بالاتر (سازگار با HPOS) |
| Elementor | ۳٫۲۰ یا بالاتر |
| Elementor Pro | اختیاری — برای Theme Builder |

## بررسی کیفیت

```bash
python3 tools/php-lint.py theme
python3 tools/php-lint.py plugin
```

ابزار فوق علاوه بر تعادل ساختار، استفاده از ساختارهای فقط-PHP8 را در پروژه‌ای که
حداقل PHP آن ۷٫۴ اعلام شده، گزارش می‌کند.
